# A股三日动量研究项目——当前事实

**问题：** 中国A股，日K趋势突破后未来三个交易日能否获得具有可执行性、成本后正期望的收益？

**执行：** GitHub Actions 北京时间工作日08:30/12:30/17:30定时；此外push CI会运行 *close research phase*，与正式定时触发不能混同。AKShare实抓历史数据，AKQuant当前仅调用API smoke，**自定义Python**进行三日策略回放，QuantStats计算假设交易序列的风险指标。自动 `records/` 留档。

**已证实：** 2026-10-28的 [run 40685553957](../records/2026-10-28/close/40685553957-a1.json) 完成，16个确定性单元测试成功，12只固定观察股票历史日K通过校验；45笔历史日线代理交易，平均成本后收益 **−0.2769%**，胜率 **42.22%**。这不是实际下单，也不是独立样本外证据。

**主要风险：** 13笔 `stop_gap` 的平均净收益 **−2.7482%**，占亏损交易绝对收益率总额的 **66.81%**。用同一批入场点做T+3日收盘简单持有假设，平均收益 **+0.1751%**，而原退出方式 **−0.2769%**；不能把这个反事实结论当成真实可成交替代策略。证据见 [EXP-0001](experiments/EXP-0001-baseline.md)。

**H01实验：** 事前记录的“沪深300及中证1000同时站上MA20和MA60”条件：45笔里33笔满足，平均 **−0.2160%**；另外12笔 **−0.4444%**。通过组仍亏钱，且整个观察池的选择与参数已被研究者看过，**不满足真实样本外**。[EXP-0002](experiments/EXP-0002-regime.md)。

**不可跨越的发布条件：** 历史完整可投资股票池、真实分钟级14:50可成交退出、价格涨跌停与T+1、可复核的资金市场宽度、独立向前的纸面信号与数据；现均未满足。程序级信号状态：`RESEARCH_ONLY_NOT_TRADE_AUTHORIZED`，**零笔授权买单**。[ADR-0001](decisions/ADR-0001-no-trade.md)。

**用户目标：** 希望一个能在出错时持续找出原因、冻结原信号、验证改进的三日追涨模型；只接受实际运行过的数据和代码结果，不接受模拟行情当成已执行。这里的“历史回放”指真实行情下的*模拟成交规则*，并不是经纪商真实交易。

**此页是维护型综述，具体事实以对应 `records/` 和 GitHub Actions 为准；数据更新须带新的run ID。**
